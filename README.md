# EduShop

Интернет-магазин на Spring Boot: каталог товаров, корзина, оформление заказа, баланс пользователя с пополнением по кодам, вишлист, отзывы и админ-панель.

## Стек

- Java 25, Spring Boot 4.1.0
- Spring MVC + Thymeleaf (серверный рендеринг)
- Spring Data JPA + PostgreSQL
- Spring Security
- Lombok
- Maven

## Возможности

**Витрина**
- Каталог товаров с фильтрами по категориям, цене и поиском
- Карточка товара, отзывы и рейтинг
- Вишлист (избранное)

**Личный кабинет**
- Регистрация и авторизация
- Корзина: добавление, изменение количества, удаление товаров
- Оформление заказа: адрес доставки → оплата с баланса → подтверждение
- История заказов
- Пополнение баланса по одноразовым кодам

**Админ-панель**
- Дашборд со статистикой
- Управление товарами: создание, редактирование, удаление
- Управление пользователями: создание, редактирование, удаление, пополнение баланса
- Управление заказами и их статусами
- Управление категориями

## Структура проекта

```
src/main/java/com/example/shop/
├── config/          # Security, web-конфигурация
├── controller/       # MVC-контроллеры (account, admin, shop)
├── dao/              # Spring Data JPA репозитории
├── dto/               # DTO для статистики
├── entity/           # JPA-сущности
└── service/           # Бизнес-логика

src/main/resources/
├── templates/        # Thymeleaf-шаблоны (user, admin, shop, fragments)
├── static/            # CSS, JS, изображения
└── application.properties
```

## Запуск

### Требования

- JDK 25
- PostgreSQL (запущенный локально или доступный по сети)
- Maven (можно использовать `./mvnw`, если Maven не установлен глобально)

### Настройка базы данных

Создайте базу и пользователя, соответствующие настройкам в `src/main/resources/application.properties`, либо отредактируйте эти настройки под свою БД:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/postgres
spring.datasource.username=admin
spring.datasource.password=8289
```

Схема БД создаётся/обновляется автоматически при старте (`spring.jpa.hibernate.ddl-auto=update`).

### Загружаемые файлы

Изображения товаров и аватары сохраняются на диске в каталоге, заданном `app.upload.dir` (по умолчанию `uploads/`), и раздаются по пути `/uploads/**`.

### Сборка и запуск

```bash
./mvnw spring-boot:run
```

или

```bash
./mvnw clean package
java -jar target/shop-0.0.1-SNAPSHOT.jar
```

Приложение будет доступно на `http://localhost:8080`.
